# Data availability

The release contains derived scenario and pairwise CSV summaries, deterministic indexes, preprocessing configuration, source metadata and the code needed to regenerate canonical data. It does not redistribute third-party raw archives. Download those archives from the official providers listed in [`data/README.md`](data/README.md), follow their licenses, and place them under the configured local directories.

The package is designed to be uploaded as one folder with independent `code/` and `data/` sections. No comparison-repository address is required by the release scripts.
