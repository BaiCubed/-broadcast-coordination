# Generated CSV data

These CSV files are real derived outputs produced by the project's final generation and evaluation pipeline.

- `mixed_scenarios/`: S1-A through S6-C, 14 files, 600 records per file.
- `pairwise/`: P001 through P105, 105 files, 30 records per file.

The files contain derived composition and evaluation summaries. They do not contain third-party raw source data. Use `configuration/scenario_config.json`, `configuration/pairwise_seed_config.json`, `index/scenario_seed_index.csv` and `index/pairwise_index.csv` to identify the scenario, pair, seed and source mapping for each record.
